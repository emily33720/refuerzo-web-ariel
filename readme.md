# 🖥️ Mantenimiento y Aseguramiento de la Operación del Sistema Informático

## Descripción del Proyecto

Página web informativa sobre el módulo de **Mantenimiento y Aseguramiento de la Operación del Sistema Informático**. Contiene información técnica, buenas prácticas, herramientas y recursos para el mantenimiento preventivo y correctivo de sistemas informáticos.

---

## 📁 Estructura del Proyecto

```
/
├── index.html        # Página principal con toda la estructura HTML
├── style.css         # Estilos visuales, animaciones y diseño responsivo
└── README.md         # Documentación del proyecto (este archivo)
```

## 📚 Contenido del Módulo

### Mantenimiento Preventivo
- Limpieza física de componentes
- Actualización de drivers y software
- Diagnóstico periódico del sistema
- Desfragmentación y optimización de discos

### Mantenimiento Correctivo
- Diagnóstico de fallos
- Reemplazo de piezas defectuosas
- Recuperación de datos
- Reinstalación de sistemas operativos

### Aseguramiento de la Operación
- Políticas de seguridad informática
- Control de acceso y autenticación
- Copias de seguridad (backup)
- Monitoreo y alertas del sistema
