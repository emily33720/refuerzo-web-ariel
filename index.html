Tipos de Mantenimiento

El mantenimiento de sistemas informáticos se clasifica según el momento de intervención y el objetivo de la acción correctiva o preventiva.

🛡️

Mantenimiento Preventivo

Conjunto de acciones planificadas para evitar fallos antes de que ocurran. Se ejecuta con regularidad para mantener el sistema en condiciones óptimas de funcionamiento.

  • Limpieza física de componentes
  • Actualización de drivers y firmware
  • Diagnóstico periódico de discos (SMART)
  • Revisión de logs del sistema
  • Verificación de temperaturas
🔨

Mantenimiento Correctivo

Intervención realizada para reparar fallos ya producidos. Su objetivo es restaurar el sistema al estado operativo en el menor tiempo posible minimizando el impacto.

  • Diagnóstico y localización de fallos
  • Reemplazo de componentes dañados
  • Recuperación de datos perdidos
  • Reinstalación del sistema operativo
  • Reparación de sectores defectuosos
📊

Mantenimiento Predictivo

Monitoreo continuo del estado del sistema para anticipar fallos basándose en indicadores de rendimiento y análisis de tendencias de degradación.

  • Monitoreo en tiempo real de métricas
  • Análisis SMART de discos duros
  • Registro de temperatura y voltaje
  • Alertas automáticas por umbrales
  • Análisis de tendencias de rendimiento
🚀

Mantenimiento Evolutivo

Mejoras y actualizaciones orientadas a adaptar el sistema a nuevos requerimientos tecnológicos, aumentar su capacidad o incorporar nuevas funcionalidades.

  • Actualización del sistema operativo
  • Ampliación de RAM y almacenamiento
  • Migración a nuevas plataformas
  • Incorporación de periféricos modernos
  • Optimización de configuraciones

Herramientas de Mantenimiento

Software especializado y equipos físicos fundamentales para el diagnóstico, mantenimiento y aseguramiento de sistemas informáticos.

💾 Software

🧹
CCleaner
Limpieza del sistema

Elimina archivos temporales, caché y entradas de registro inválidas para optimizar el rendimiento del sistema operativo.

🔬
CrystalDiskInfo
Diagnóstico de discos

Monitorea el estado S.M.A.R.T. de discos duros y SSD, mostrando temperatura y predicción de fallos.

🧠
MemTest86
Diagnóstico de RAM

Herramienta booteable para detectar errores en módulos de memoria RAM con pruebas exhaustivas.

📡
Wireshark
Análisis de red

Captura y analiza paquetes de red en tiempo real para detectar problemas de conectividad y seguridad.

🛡️
Malwarebytes
Seguridad

Detecta y elimina malware, spyware, ransomware y otras amenazas que afectan el rendimiento del sistema.

🔧
HWiNFO
Monitoreo de hardware

Muestra información detallada de todos los componentes del hardware incluyendo sensores en tiempo real.

🔌 Hardware

⚡
Multímetro
Medición eléctrica

Mide voltaje, corriente y resistencia en fuentes de poder y componentes electrónicos del sistema.

🌡️
Termómetro IR
Temperatura

Mide temperatura sin contacto en componentes del motherboard, procesador y zonas críticas del gabinete.

🌬️
Compresor de Aire
Limpieza física

Expulsa polvo acumulado en disipadores, ventiladores y ranuras de componentes con aire comprimido a presión.

🔌
POST Card
Diagnóstico de arranque

Tarjeta diagnóstica que muestra códigos POST para identificar fallos durante el proceso de arranque del sistema.

Seguridad y Aseguramiento

Políticas, procedimientos y controles técnicos para garantizar la disponibilidad, integridad y confidencialidad del sistema informático.

01

Copias de Seguridad (Backup)

Estrategia 3-2-1: mantener 3 copias de los datos en 2 medios diferentes, con 1 copia fuera del sitio. Automatizar backups diarios incrementales y semanales completos.

02

Control de Acceso

Principio de mínimo privilegio: cada usuario solo accede a los recursos necesarios para su función. Autenticación multifactor (MFA) para cuentas privilegiadas.

03

Actualizaciones y Parches

Aplicar actualizaciones de seguridad dentro de las primeras 72h de su publicación. Mantener un inventario actualizado de versiones de software en producción.

04

Monitoreo y Auditoría

Registrar todos los eventos de acceso y modificaciones del sistema en logs inmutables. Revisar alertas diariamente y establecer correlaciones de eventos sospechosos.

05

Plan de Recuperación (DRP)

Documento que define pasos, responsables y tiempos de recuperación ante incidentes. Incluye RTO (tiempo de recuperación objetivo) y RPO (punto de recuperación objetivo).
