🖥️ Mantenimiento y Aseguramiento
del Sistema Informático

Módulo informativo sobre buenas prácticas, herramientas, comandos y seguridad en sistemas computacionales.

Tipos de Mantenimiento

El mantenimiento asegura el correcto funcionamiento del hardware y software.

✅ Preventivo

Se realiza de forma programada para evitar fallos. Incluye limpieza de componentes, actualización de drivers y revisión de temperatura.

Windows CMD
chkdsk C: /f /r Verifica y repara errores en el disco duro

🔧 Correctivo

Se aplica cuando ya existe un fallo. Diagnostica y repara daños en hardware, SO o aplicaciones.

Windows CMD (Admin)
sfc /scannow Escanea y restaura archivos del sistema

📊 Predictivo

Monitorea el sistema continuamente para anticipar fallos antes de que ocurran usando logs y métricas.

Windows Run
eventvwr.msc Visor de eventos del sistema operativo

Aseguramiento de la Operación

La seguridad protege los datos y garantiza la continuidad del servicio.

🛡️ Antivirus

Instalar y mantener actualizado el software antivirus. Realizar escaneos periódicos completos.

PowerShell (Admin)
Update-MpSignature Actualiza definiciones de Windows Defender

💾 Backups

Realizar copias de seguridad regulares en medios externos o en la nube para recuperación ante desastres.

Windows CMD
xcopy C:\Docs D:\Backup /e /i /y Copia carpeta con subdirectorios al backup

🔐 Control de Acceso

Gestionar usuarios, contraseñas seguras y permisos para limitar el acceso a recursos críticos.

Windows CMD (Admin)
net user Lista todos los usuarios del sistema

🌐 Red y Firewall

Configurar el cortafuegos y monitorear el tráfico de red para detectar accesos no autorizados.

Windows CMD
ipconfig /all Muestra configuración completa de red

Comandos Esenciales

Comandos clave para diagnóstico y mantenimiento del sistema.

Windows Run / CMD
msconfig 📌 Abre configuración del sistema: inicio, servicios y arranque
Windows CMD
tasklist 📌 Lista todos los procesos en ejecución en memoria RAM
Windows CMD (Admin)
taskkill /IM proceso.exe /F 📌 Termina forzosamente un proceso específico
Windows CMD (Admin)
defrag C: /U /V 📌 Desfragmenta el disco C: mostrando progreso detallado
Windows CMD
systeminfo 📌 Muestra información completa del hardware y software instalado
Windows / Linux CMD
ping 8.8.8.8 -t 📌 Prueba continua de conectividad hacia el servidor DNS de Google
PowerShell / CMD (Admin)
DISM /Online /Cleanup-Image /RestoreHealth 📌 Repara la imagen del sistema operativo Windows

Glosario de Términos

/>
Hardware
Componentes físicos del computador: CPU, RAM, disco duro, teclado, monitor.
Software
Conjunto de programas e instrucciones que controlan el hardware del sistema.
Sistema Operativo (SO)
Programa principal que gestiona los recursos del equipo. Ej: Windows, Linux, macOS.
Driver / Controlador
Software que permite al SO comunicarse con dispositivos de hardware específicos.
BIOS / UEFI
Firmware que inicializa el hardware antes de cargar el sistema operativo.
Disco Duro (HDD/SSD)
Dispositivo de almacenamiento permanente. SSD es más rápido; HDD tiene mayor capacidad por menor precio.
RAM (Memoria)
Memoria temporal de acceso rápido que almacena datos de programas en ejecución.
Malware
Software malicioso diseñado para dañar o tomar control del sistema. Incluye virus, troyanos y ransomware.
Firewall
Sistema de seguridad que controla el tráfico de red y bloquea accesos no autorizados.
Backup
Copia de seguridad de datos para restaurar el sistema en caso de pérdida o fallo.
Fragmentación
División de archivos en partes dispersas en el disco, lo que reduce el rendimiento de lectura.
Desfragmentación
Proceso que reorganiza los datos fragmentados en el disco para mejorar el rendimiento.
